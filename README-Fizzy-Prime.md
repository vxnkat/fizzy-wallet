## 📖 Overview

**Fizzy Prime** is a personal finance dashboard concept built around a simple idea: make important everyday information easy to understand at a glance.

The dashboard brings together your card balance, overall financial progress, today's schedule, and logging streak in one calm, easy-to-navigate interface. Its lavender colour palette and card-based layout keep the experience clear without overwhelming the screen.

## ✨ Features

| Feature | Description |
| --- | --- |
| **Card Balance** | View your current balance and selected account period. |
| **Overall Progress** | See a summary of income, expenses, budget usage, and goals. |
| **Today's Schedule** | Keep planned payments and daily items in view. |
| **Logging Streak** | Follow your consistency over time. |
| **Quick Actions** | Reach frequently used app sections from the dashboard. |
| **Bottom Navigation** | Move between the app's main areas. |
| **Settings** | Access app preferences. |

*The feature list reflects the dashboard design shown in the project preview. Actual functionality depends on the app implementation.*

## 🎨 Interface & Design

- Rounded cards with subtle depth
